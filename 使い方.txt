■ Phase 1-3 で実装された機能
====================================================

  ▶ メインウィンドウ
    ─ 上部メニュー：ファイル / 編集 / 表示 / ツール / ヘルプ
    ─ 左：カテゴリツリー（12カテゴリ）
    ─ 中央：項目リスト（DataGrid・危険度マーク表示）
    ─ 下：ステータスバー

  ▶ カテゴリフィルタ
    ─ 左ツリーでカテゴリを選択 → DataGrid が絞り込み

  ▶ 検索バー
    ─ 左上の検索ボックスに入力 → タイトル・説明の部分一致でリアルタイムフィルタ

  ▶ 設定編集ダイアログ
    ─ DataGrid をダブルクリック → 個別項目編集ウィンドウ
    ─ フッターボタン：OK / キャンセル / 適用 / 戻す / 保存 / 読込 / ヘルプ
    ─ 適用時：自動バックアップ → 危険度Redなら復元ポイント確認 → レジストリ書込

  ▶ テーマ切替
    ─ 表示メニュー → ライト / ダーク / システム連動 を選択
    ─ %APPDATA%\WinKnobs\settings.json に永続化

  ▶ ツールメニュー（外部起動）
    ─ レジストリエディタ・コントロールパネル・msconfig・GodMode
    ─ シェル再起動・ログオフ・再起動・シャットダウン（30秒猶予つき）

  ▶ バックアップ
    ─ 保存先：%APPDATA%\WinKnobs\backup\
    ─ 最大10件保持・古いものは自動削除
    ─ 適用前に .reg ファイルを自動エクスポート
    ─ 「戻す」コマンドで直前バックアップから復元

  ▶ 復元ポイント（危険度🔴項目）
    ─ 適用前に確認ダイアログ → PowerShell Checkpoint-Computer 実行
    ─ 24時間制限を検知して UI に通知

■ 開発者向け：ビルド方法
====================================================

  ▶ 通常ビルド（開発用）
    cd src\WinKnobs
    dotnet build

  ▶ 起動（開発用）
    dotnet run

  ▶ 配布版ビルド（self-contained 単一ファイル）
    dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
    → bin\Release\net10.0-windows\win-x64\publish\WinKnobs.exe（約127MB）

  ▶ 配布時の注意
    publish フォルダの中身を「丸ごと」コピー（WPF ネイティブDLL同梱）

■ テスト方法（Phase 1-3 完了後）
====================================================

  ▶ ホスト（実機）でのテスト
    ❌ レジストリ書換は実機で絶対にやらない（OS起動不能リスク）

  ▶ 仮想Windows 11 でのテスト
    ─ Hyper-V構築ガイド.md の手順で仮想マシン構築

    ─ WinKnobs publish フォルダを共有フォルダ経由で転送
    ─ Hyper-V構築ガイド.md の T-1〜T-10 を順次実施

■ うまくいかないとき
====================================================

  ❓ ビルド失敗：System.Windows.ThemeMode と衝突
     → MainViewModel.cs 冒頭の `using ThemeMode = WinKnobs.Services.ThemeMode;` を確認

  ❓ publish エラー：パッケージ復元失敗
     → `dotnet restore` を先に実行
     → ~/.nuget/packages のキャッシュ削除

  ❓ 起動時に XamlParseException
     → publish フォルダの WPF ネイティブDLLが揃っているか確認
     → Themes\Light.xaml / Dark.xaml が pack URI で解決できているか

  ❓ バックアップが空ファイル
     → アクセス拒否サブキーが含まれている可能性
     → BackupService の ValidateBackupFile が検知して例外を投げる

  ❓ 復元ポイント作成失敗
     → 24時間制限 / 管理者権限 / システム保護無効 のどれかをエラーメッセージで案内
     → コントロールパネル → 回復 → システムの復元の構成 で有効化
