## 🔧 @plan-validator 反映（本文より優先・2026-06-11）

1. 🔴 **致命1：Apply の「exit $LASTEXITCODE 一発」禁止＝途中失敗の握りつぶし防止**。各 Set- の失敗を個別捕捉（`$ErrorActionPreference='Stop'`＋try/catch 集約）し「N項目中M項目成功」を構造化出力。Outcome に **`PartiallyApplied`** 追加（WSL done-stack と対称）。最後の Disable-NetAdapterPowerManagement 成功が先行失敗を 0 で上書きする経路を塞ぐ。
2. 🔴 **致命2：一律 0 書き込み禁止＝`ValidRegistryValues` ガード必須**。TryParseSnapshot で `ValidRegistryValues` も取得し、**0 が有効値域に含まれるキーワードだけ** 0 を書く。含まれない項目はスキップ（機種によって enum 値域・意味反転があり得る）。引き継ぎ指示書 §2「動的生成」の趣旨をここで回収。
3. 🔴 **致命3：RegistryValue は文字列のまま厳密保持**。snapshot・Apply・Restore とも文字列で扱う（REG_SZ 格納）。一致比較は**数値正規化後**（`"00000000"`/`"0"` 混在吸収）。xUnit で混在ケース検証。
4. ⚠️ **重要4：アダプタ識別は Name でなく `InterfaceGuid` 統一**。日本語アダプタ名（「イーサネット」）の CP932 化け→AdapterNotFound 誤分類を回避。コマンドは **`-EncodedCommand`（Base64 UTF-16LE）** で渡す。Backup FeatureKey（GUID）と識別軸も一貫。
5. ⚠️ **重要5：夜間モード blob はのんさん実機構成（マルチモニタ/HDR）の blob を必ず xUnit サンプルに入れる**。VM 単一仮想ディスプレイの Parse 成功＝実機成功にならない。実機採取は読取のみ（無害）なので Step3 冒頭で実施。
6. ⚠️ **エッジ1：Apply 直前に InterfaceGuid 再確認**（snapshot 採取後のアダプタ差替 TOCTOU・不一致なら中止＝powercfg GUID 固定と同思想）。
7. ⚠️ **エッジ2：AdvancedProperty 0件でも電源管理ロックはスキップしない**。no-op 早期 return 禁止・状態表示は「省電力項目」「電源オフ許可」の2軸を独立更新。
8. ⚠️ **エッジ3：Network ペイン内の全アダプタ操作（DNS 個別設定＋NIC省電力）を1本のペイン共通 Busy で直列化**（`IsNicPowerBusy` 単独では DNS 操作との NIC 再初期化競合を防げない）。
9. ⚠️ **エッジ4：自動ロールバックの非対称**＝夜間モード（blob 丸ごと＝常に安全）は自動ロールバック維持／**NIC（値単位）は自動書き戻しせず**「復元ボタンを案内する警告表示」に留める（誤発火による二次破壊防止）。
10. ℹ️ 指摘「v0.2.1↔v0.2.2 夜間モード二重計上」は**誤解**＝夜間モードは v0.2.1 で未実装（Step6 スキップ・v0.2.2 送り済・commit `359bf0e` に NightLightHelper 無し）。採番矛盾なし。

## 0. 実装前のダメ出し（先に言う問題点）

1. 🔴 **VM では NIC省電力の実トグル検証ができない**：Hyper-V 仮想NIC（Microsoft Hyper-V Network Adapter）には `*EEE`/`ULPMode` 等の省電力 AdvancedProperty が存在しない。VM で検証できるのは「該当キーワード無し→安全スキップ（no-op）」経路と UIA 非破壊のみ。**実トグルはのんさんホスト実機（Z370・Intel NIC）でしか検証できない**＝適用→復元往復を慎重に（復元一致まで確認・有線なので Wi-Fi より安全）。
2. 🔴 **適用時に NIC が数秒リセット＝通信が切れる**：`Set-NetAdapterAdvancedProperty` は適用時にアダプタ再初期化が走る。RDP・リモート経由で操作中なら**自分の接続が切れる**。v0.1.18 の自己セッション判定（`GetSystemMetrics(SM_REMOTESESSION)`）を流用し、リモート接続中は強警告（既定いいえ）。ローカルでも「数秒切断」を確認ダイアログに明記。
3. 🔴 **夜間モードは非公開フォーマット**（CloudStore blob）：壊すと夜間モード UI がグレーアウトする既知事例。v0.2.0 §3 の「1バイトでも想定外なら書込拒否＋blob 丸ごと Base64 退避＋縮退逃げ道（読取表示＋ms-settings ジャンプ）」を厳守。**のんさんは夜間モード50〜60を常用**（[[user_display_preference]]）＝開発機で壊すと実害が出る。実機 blob 採取・書込検証は**先に VM で**（VM にも CloudStore はある・夜間モードを一度 ON にして blob 生成してから）。
4. ⚠️ **DisplayName でなく RegistryKeyword で判定**（引き継ぎ指示書 §4）：「Energy-Efficient Ethernet」「省電力イーサネット」等はドライバ・言語でブレる。コマンド構築・判定・退避キーはすべて `RegistryKeyword` 基準。UI 表示だけ DisplayName（実列挙値）を使う。
5. ⚠️ **PowerShell 出力のパースはロケール非依存に**：`Get-NetAdapterAdvancedProperty` は **JSON 化して受ける**（`ConvertTo-Json -Compress`）。表形式パースは禁止（v0.2.1 Boost の教訓と同類）。
6. **「触らない」検討**：引き継ぎ指示書 優先度B（受信バッファ最大化・TCP 可視化）と「個別調整/上級者向け」UI 階層は **v0.2.2 に入れない**（過剰実装回避）。オフロード系（`*LsoV2*`/`*RSS` 等）は恒久スコープ外。プリセット＋復元の最小形で出し、需要があれば拡張。

## 2. 各項目設計

### 2-1. 夜間モード色温度（`desktop.nightLightStrength`）🔶最難関

[v0.2.0_QuickWin_設計ドラフト.md](v0.2.0_QuickWin_設計ドラフト.md) §3 ＋「🔧反映」3・8 のまま採用。要点：

- 新規 `Services/NightLightHelper.cs`（純粋関数集約・xUnit 重点）：
  - `TryParseSettings(byte[])`＝構造検査しながら色温度抽出。**1バイトでも想定外なら false（書込しない）**。
  - `BuildPatchedSettings(original, kelvin, …)`＝色温度フィールドのみ差替・他バイト原本維持。**タイムスタンプは blob 内既存値 +1**（DateTime.Now 直挿し禁止・CDPUserSvc 逆転負け対策）。
  - クランプ 1200〜6500K。
- SettingItem＝Command 型・Choices「6500K(弱)/5000K/4000K/2700K(強)/1200K(最強)」・Category=Desktop・Risk 🟡・HKCU 昇格不要・即時反映。
- Read 失敗→「（読取不可・公式設定で変更してください）」＋Apply 拒否。**blob「キー/Data 値なし」（夜間モード未使用PC）→「夜間モードを一度 ON にしてから調整してください」案内**（v0.2.1 ドラフト 反映8・NRE 防止）。
- Backup＝blob 丸ごと Base64・maintenance ストア first-touch（`SaveMaintenanceOriginalIfAbsent` 流用・FeatureKey=`nightLight`）。復元は丸ごと書戻し＝解釈不要で常に安全。
- Apply 直後に Read 検証（読み戻し一致）→不一致なら Base64 退避から自動ロールバック。
- ON/OFF（bluelightreductionstate）は触らない。
- **縮退逃げ道**：実機（VM 先行）で Parse 成功率が不安定なら「読取表示のみ＋`ms-settings:nightlight` ジャンプ」へ縮退し書込は次版送り。

**工数 2-3h。テスト：xUnit（実 blob 複数サンプルの Parse/Patch ラウンドトリップ・タイムスタンプ+1 検証）＋VM で書込→公式UI追従→CloudStore に戻されないか→復元、を一式。**

### 2-2. NIC省電力プリセット（`network.nicPowerSaving`）

#### スコープ（引き継ぎ指示書 優先度Aの3点のみ）

1. **省電力OFF**：選択アダプタの AdvancedProperty のうち、**実在するものだけ** 0 に設定
   - 対象 RegistryKeyword 固定リスト：`*EEE` / `EeePhyEnable` / `EEELinkAdvertisement` / `ULPMode` / `AutoPowerSaveModeEnabled` / `GreenEthernet` / `EnableGreenEthernet` / `PowerSavingMode`
   - 列挙に無いキーワードは**触らない・エラーにしない**（ドライバ差吸収）。1つも無ければ「このアダプタに省電力設定はありません」no-op。
2. **NIC電源管理ロック**：`Disable-NetAdapterPowerManagement -Name <nic>`（「電力節約のためにオフにできる」相当を無効化）
3. **元に戻す（復元）**：適用前スナップショットから AdvancedProperty 値＋PowerManagement 状態を書戻し

#### UI（Network 専用ペイン内・新セクション）

- 既存のアダプタ選択 ComboBox（v0.1.7 DNS 個別設定）を共用。**物理NICのみ列挙**（`Get-NetAdapter -Physical`・Hyper-V/VPN 仮想NIC 除外）— 既存列挙が非 Physical なら本機能側でフィルタ。
- ボタン2つ＋状態表示1行：
  - `BtnNicPowerSavingOff`「省電力をOFFにする（安定重視）」→ 確認ダイアログ（「適用時に数秒通信が切れます」明記・リモートセッション中は ConfirmDestructive 強警告・既定いいえ）
  - `BtnNicPowerSavingRestore`「元に戻す」（退避なしはグレー・CanExecute）
  - `NicPowerStatusText`：現在状態（例「省電力: 有効 3項目 / 電源オフ許可: ON」）・世代カウンタパターンで非同期リフレッシュ
- 説明は中立：「ラグ・切断対策に効く一方、待機消費電力が微増します」（一律推奨しない）

#### 実装（Sysmain/WSL 同型）

- 新規 `Services/NicPowerHelper.cs`（純粋関数）：
  - `BuildReadCommand(adapterName)`：`Get-NetAdapterAdvancedProperty`＋`Get-NetAdapterPowerManagement` を **ConvertTo-Json -Compress** で1回取得
  - `TryParseSnapshot(json)`：RegistryKeyword→RegistryValue 辞書＋AllowComputerToTurnOffDevice を厳密 DTO 化（想定外は false）
  - `BuildApplyCommand(snapshot)`：実在キーワード分のみ `Set-NetAdapterAdvancedProperty -RegistryKeyword <k> -RegistryValue 0 -NoRestart` 連結＋最後に `Disable-NetAdapterPowerManagement`＋`exit $LASTEXITCODE`
  - `BuildRestoreCommand(snapshot)`：退避値の書戻し（PowerManagement 含む）
  - `Classify(exitCode, output)`＝ElevationClassifier 委譲＋`AdapterNotFound` 分類（適用時にアダプタが消えている TOCTOU）
  - アダプタ名は **PowerShell 単一引用符エスケープ**（`'` 二重化）で注入防止（HyperVHelper の raw トークン検証と同思想）
- 新規 `Services/NicPowerService.cs`：powershell.exe・**120秒タイムアウト**（NIC 再初期化が遅い個体差を考慮・60秒から延長）・Kill(entireProcessTree)・stderr 非同期（v0.2.1 I-2 踏襲）
- Backup＝**アダプタ GUID 単位 first-touch**・maintenance ストア（FeatureKey=`nicPower_<InterfaceGuid>`）。スナップショットは「Read で取れた実在キーワードと現在値」のみ＝復元で存在しない値を書かない。
- Busy＝既存 `IsSystemFeatureBusy` に乗せない（再起動系でない）→ Network ペイン専用 `IsNicPowerBusy`。
- Risk 🟡／要管理者（非昇格は AccessDenied 案内）／再起動不要・即時（数秒切断）。

**工数 2-3h。テスト：xUnit（BuildCommand/TryParseSnapshot/Classify/エスケープ）＋VM＝「省電力キーワード無し→no-op 文言」「非昇格 AccessDenied」「UIA 非破壊（確認ダイアログ・キャンセル非実行）」＋**ホスト実機＝適用→Get-NetAdapterAdvancedProperty 実測→復元→一致確認**。**
