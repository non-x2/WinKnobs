## 0. ⚠️ 実装前の必読・安全方針（ダメ出し）

1. 🔴 **リモートデスクトップ有効化はセキュリティ直結**。`fDenyTSConnections=0` ＋ ファイアウォール開放は**攻撃面を広げる**。
   - 危険度＝🔴 Red（WinKnobs で初の Red トグル候補）。`ConfirmDestructive` 相当の強い確認ダイアログ必須。
   - 既定は触らない（OFF のまま）。ON にするのは明示操作のみ。Description に「外部からPCに接続を許可します。公共Wi-Fi・共有PCでは有効にしないでください」と明記。
2. 🟡 **多くが管理者権限必須**（HKLM・サービス・PowerShell）。WinKnobs はこれまで HKCU 中心（管理者不要）。
   - 昇格フローは Network v0.1.7 の `HandleElevationNeeded`/`RequestRestartAsAdministrator`/`LooksLikeAccessDenied` を**複製/共通化して再利用**。
   - **実トグルは VM 実機検証必須**（ホスト実行は のんさんの実環境を変える）。VM チェックポイント `Before_v0.1.14_Maintenance` を取得してから検証。
3. ♻️ **メモリ圧縮・SysMain は既に v0.2.0 Quick Win 計画済み**（`docs/v0.2_候補項目集_v2.md`：`system.memoryCompression` スコア9⭐）。
   - 本 v0.1.14 で前倒し実装 → **v0.2.0 リスト・CHANGELOG Unreleased・README から該当項目を削除**して二重計上を防ぐ（透明効果の教訓）。
4. ✅ **復元ポイント作成は既に実装済み**（`RestorePointService` ＋ メニュー `MenuCreateRestorePoint`）。新規で作らず**既存活用**。「システムの保護 ON/OFF」だけが新規。
5. 📦 **PowerShell 実行基盤**：`RestorePointService` が `Checkpoint-Computer` を PowerShell で呼ぶ実装を持つ。これを汎用化した `ElevatedCommandService`（仮）に切り出し、System Restore / Memory圧縮 / Firewall を集約する（Network plan-validator 重要3「PowerShell基盤が無い」への対応）。

## 2. 4項目の仕様（実装順＝危険度の低い順）

### 段階A（HKCU・管理者不要・自己検証可）→ 先行リリース可

#### 項目1：タスクマネージャを使えるようにする（DisableTaskMgr）
- レジストリ：`HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\System\DisableTaskMgr`（REG_DWORD）。1=無効化／0 or 未設定=使える（既定）。
- **管理者不要**（HKCU ポリシー）。危険度🟡（自分をロックアウトしうる）。
- Command 2択（ScrollbarHelper 同型・JSON 退避）。Choices=「使える（既定）」「無効にする」。既定＝Choices[0]＝未設定/0。
- ⚠️ Description：「無効にすると Ctrl+Shift+Esc でタスクマネージャを開けなくなります。WinKnobs から元に戻せます」。
- 純粋関数 `TaskManagerHelper`（IsDisabled/ValueForLabel/LabelForValue/CoerceInt 委譲）。
- ＋ 補助：純正ランチャー（`taskmgr.exe` 起動）を別項目 or メニューで（`ExternalLauncherService` 流用・🟢）。

### 段階B（管理者必須・VM検証必須）

#### 項目2：システムの保護（システム復元）ON/OFF
- 手段：PowerShell `Enable-ComputerRestore -Drive "C:\"` / `Disable-ComputerRestore -Drive "C:\"`（管理者）。
- 状態取得：`vssadmin list shadowstorage` or レジストリ `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\SystemRestore\RPSessionInterval`（要実機確認）。純粋関数で stdout/レジストリをパース。
- 危険度🟡。退避：適用前の有効/無効状態を JSON 保存 → Restore で元に戻す。
- 既存 `RestorePointService`（復元ポイント作成）と**セット運用**（保護ON→ポイント作成 の導線）。
- ⚠️ 昇格：`HandleElevationNeeded` 経由。失敗時は管理者再起動を促す。

#### 項目3：メモリ圧縮 ON/OFF（v0.2.0 から前倒し）
- 手段：PowerShell `Enable-MMAgent -mc` / `Disable-MMAgent -mc`（管理者）。状態：`Get-MMAgent` の `MemoryCompression` を bool パース（純粋関数）。
- 危険度🟡。退避：適用前の bool を JSON 保存。
- Description：「メモリを圧縮して空きを増やす機能。RAM が大きい PC では切ると CPU 負荷が減ることがあります（中立・一律推奨しない）」。
- （任意・同カテゴリ）SysMain サービス ON/OFF：`Set-Service SysMain -StartupType` ＋ `Stop/Start-Service`（管理者）。v0.2.0 から前倒すなら同時に。

#### 項目4：リモートデスクトップ ON/OFF（🔴 最高リスク・最後に実装）
- 本命：`HKLM\System\CurrentControlSet\Control\Terminal Server\fDenyTSConnections`（REG_DWORD）。0=許可／1=拒否（既定）。
- 補助：ファイアウォール `netsh advfirewall firewall set rule group="remote desktop" new enable=Yes/No`（`ExternalLauncherService.RunNetsh` 流用）。さらに NLA `…\WinStations\RDP-Tcp\UserAuthentication=1`（推奨・セキュア）。
- 危険度🔴。**ConfirmDestructive 強確認**（既定いいえ）＋ Description にセキュリティ警告。
- 退避：fDenyTSConnections ＋ ファイアウォール状態 ＋ UserAuthentication を JSON 保存。RevertAll に明示順で組込。
- 昇格必須（HKLM）。VM 実機で「ON→接続可能・OFF→不可・戻す→原状」を検証。

## 3. 共通アーキ（次セッションの実装メモ）

- **昇格ヘルパー共通化**：Network の `HandleElevationNeeded`/`RequestRestartAsAdministrator`/`LooksLikeAccessDenied` を `Services/ElevationHelper`（仮）へ集約（M-1 リファクタ相当）。Startup/Network/Maintenance で共用。
- **PowerShell 実行基盤**：`RestorePointService` の PSI(PowerShell) 呼び出しを `ElevatedCommandService`（仮）に汎用化。stdout/stderr/exitcode を返し、純粋関数でパース（System Restore 状態・MMAgent 状態）。
- **退避ストア**：Network 同様 `%APPDATA%\WinKnobs\backup\maintenance\originals.json`（first-touch-wins・原子的置換）。
- **純粋関数（xUnit 対象）**：各 Helper の Label↔値・状態パーサ・コマンド引数生成。I/O は VM 検証。
- **危険度マーク**：🔴 Red は WinKnobs 初。`RiskLevel.Red` は既存（SettingItem.cs:13）。Red 用の UI 表示（赤バッジ・強確認）が既に揃っているか実装時に確認。
