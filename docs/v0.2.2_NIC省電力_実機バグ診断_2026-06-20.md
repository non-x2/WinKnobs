# v0.2.2 NIC省電力 実機バグ診断（2026-06-20・実機検証 06-20-1）

## 症状
実機検証（経路4・昇格UIAドライバ `_v022_nic_host_verify.ps1`）で NIC省電力 Apply が
**「❌ 省電力OFFに失敗しました（4アダプタ）／アダプタの現在設定を読み取れなかったため安全のため中止」**。
NIC実値は無傷（Before=After=Restore 完全一致）・ネット断なし・退避残骸なし（Restore＝戻す対象なし）。

## 真因（確定）
1. **列挙ソース不一致**。
   - リスト生成：`NetworkService.GetActivePhysicalAdapters()` ＝ .NET `NetworkInterface.GetAllNetworkInterfaces()`
     ＋ `IsPhysicalAdapter(type,status,description)`（Status=Up・Type=Ethernet/Wireless・Description にマーカー
     〔Virtual/Hyper-V/TAP/Tunnel/Loopback…〕を含まない、の**ヒューリスティック**）。
   - 読取/適用：`NicPowerHelper.BuildReadCommand/BuildApplyCommand` ＝ **`Get-NetAdapter -Physical` ＋ InterfaceGuid**。
2. 検証時リストに **4枚**＝Intel 1枚＋ **幻3つ**（Microsoft 疑似/エミュレータ系の Ethernet/Up・共通ノード）。
   幻は Microsoft 疑似/エミュレータ系（LDPlayer 等）の**一時的な Ethernet/Up** インターフェースで、
   Description にマーカーを含まず `IsPhysicalAdapter` を**すり抜けた**。但し `Get-NetAdapter -Physical` には出ない
   → 読取が `WINKNOBS_ADAPTER_NOT_FOUND` → `TryParseSnapshot=null` → Apply「失敗」。検証後は幻3つは消滅（揮発）。
3. `.NET NetworkInterface` には「物理か」の確実なフラグが無い＝**Description ヒューリスティックは原理的に漏れる**
   （LDPlayer/独自VM/コンテナの命名は無数）。**唯一の信頼できる真実源は `Get-NetAdapter -Physical`**（WMI HardwareInterface）。
4. **未解明（防御で対処）**：昇格時 Intel 単体も failed（集計 ok=0）。ただし非昇格で WinKnobs と同じ
   `-EncodedCommand` 読取を再現すると Intel は **exit=0・stderr=0・正常JSON 8997B**。
   → `RunPowerShell` は combined＝stdout+stderr を `TryParseSnapshot` に渡すため、**stderr 混入で JSON パース崩れ→null**
   の疑い。防御として TryParseSnapshot を「combined から `{…}` を抽出してから Deserialize」に強化し、実機再テストで確認。
5. **影響範囲**：`GetActivePhysicalAdapters` は **DNS機能も共用**（`ResolveTargets`）＝同じ幻混入リスク（DNSも実機未確認）。

## 修正方針（v0.2.2 で実施・Option 2＝のんさん選択）
- **A（列挙統一）**：`GetActivePhysicalAdapters` を `Get-NetAdapter -Physical` の InterfaceGuid 集合と突き合わせ、
  **両方に在るアダプタだけ**返す。PowerShell 取得に失敗（exit≠0/例外）したときは従来の .NET ヒューリスティックに
  フォールバック（list を空にしない＝可用性優先）。→ **list ≡ read ≡ apply**。DNS も同時に整合。
- **B（読取の堅牢化）**：`NicPowerHelper.TryParseSnapshot` を combined から最初の `{` ～最後の `}` を抽出してから
  `Deserialize`（stderr/警告の前置混入に耐性）。
- **検証**：unit 回帰（A/B 追加）→ 実機再テスト（昇格・Intel 単体で Apply→Restore 往復成功 ＋ raw read の exit/stderr 採取）。

## 無害確認（このセッションの実機操作）
NIC実値 Before=After=Restore 一致・ネット瞬断なし・退避残骸なし。夜間モード色温度は経路1検証OK（マーカー一意）。
