## A. ナビゲーションウィンドウにすべてのフォルダーを表示（v0.3.18・`shell.navPaneShowAllFolders`）

- **レジストリ**：`HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\Advanced\NavPaneShowAllFolders`（REG_DWORD・1=表示/0=非表示。[出典](https://www.elevenforum.com/t/turn-on-or-off-show-all-folders-in-navigation-pane-of-file-explorer-in-windows-11.2535/)）。
- **既定 OFF**（未設定＝非表示）。値 1=ON がユーザー視点と一致＝**InvertDisplay 不要**。
- **型**：宣言的 Boolean（`AutoCheckSelect` 踏襲）。`RecommendedValue=false`・`DefaultValue=false`（OS 既定と一致＝復元無害）。
- **カテゴリ**：Shell。**RestartScope**：Explorer（エクスプローラ再起動で反映）。

## B. ファイル削除時に確認ダイアログを表示（v0.3.19・`shell.confirmFileDelete`）

- **レジストリ**：`HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\Explorer\ConfirmFileDelete`（REG_DWORD・1=確認する/0=確認しない。[出典](https://www.elevenforum.com/t/enable-or-disable-delete-to-recycle-bin-confirmation-dialog-in-windows-11.11003/)）。
- **既定 OFF**（Win11 はゴミ箱への削除時に確認を出さない＝未設定）。値 1=ON（確認する）がユーザー視点と一致＝InvertDisplay 不要。
- **型**：宣言的 Boolean。`RecommendedValue=true`（うっかり削除防止に確認 ON 推奨）・`DefaultValue=false`（OS 既定）。
- **カテゴリ**：Shell。**RestartScope**：Explorer。
- **注意点（plan-validator 確認）**：`Policies\Explorer` 配下だが HKCU・管理者不要のユーザーポリシー（グループポリシーで未管理なら自由に書ける）。🟢 妥当か確認。

## C. クイックアクセスに「最近使ったファイル」を表示（v0.3.20・`shell.showRecent`）

- **レジストリ**：`HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\ShowRecent`（REG_DWORD・1=表示/0=非表示。[出典](https://www.elevenforum.com/t/file-explorer-displaying-quick-access-within-home-via-registry.21120/)）。
  - 設定＝エクスプローラ「…> オプション > 全般 > プライバシー >『最近使ったファイルを表示する』」。
- **既定 ON**（未設定＝表示）。→ **宣言的 Boolean は不可**（OFF→戻すで未設定 ON に戻らない）。**Command 型2択＋ValueExisted**（Start_TrackProgs と同型）。
- **選択肢**：「表示する（既定）」/「表示しない」。Read：1→表示する／0→表示しない／未設定→表示する（既定 ON）。Apply：表示する→1／表示しない→0／想定外→no-op。Backup：existed＋値。Restore：existed=false で **DeleteOrThrow**。
- **カテゴリ**：Shell。**RestartScope**：Explorer。

## 確認したい論点（plan-validator 向け）

- **Q1（B のカテゴリ・危険度）**：削除確認を「OFF（確認しない）」にするのは誤削除リスクが上がる。🟢 のままでよいか、説明に警告を足すべきか。`Policies\Explorer` 書き込みの 🟢 妥当性。
- **Q2（A/B の既定 OFF 宣言的 Boolean）**：既定 OFF なので reg import 復元の不完全さは無害（値 0 書込≒未設定）。この判断の是非。
- **Q3（C の ShowRecent と ShowFrequent の取り違え）**：出典に「ShowRecent=フォルダ／ShowFrequent=ファイル」と逆転記述あり。一般的には **ShowRecent=最近使ったファイル / ShowFrequent=よく使うフォルダー**。この同定の妥当性（本実装は ShowRecent=ファイルとして Title 記載）。
- **Q4（RestartScope）**：3項目とも Explorer で妥当か（A 出典は「サインアウト or エクスプローラ再起動」）。

## 🔁 plan-validator 反映（2026-06-30）

- **B を Command 型へ変更（致命1）**：`Policies\Explorer` は未存在から新規作成され得る。宣言的 Boolean の汎用 Backup（`BackupService.ExportKey`）はキー不在時に `[-HKCU\…\Policies\Explorer]` 削除マーカーを生成し、復元で**キーごと削除＝他のユーザーポリシー値を巻き添え**（2026-06-10「Boolean 復元のキー巻き添え」の Policies 版）。→ B は **Command 型2択（確認する/確認しない）＋ValueExisted＋値単位 DeleteOrThrow**（`_registry.DeleteValue(path,name)` は値単位でキーを消さない）。これで巻き添えを構造的に回避。
- **B の誤削除警告強化（指摘4）**：CommandAction.Apply は Dialog を持てない（純粋ロジック注入）ため二段ダイアログは不可。代わりに Description 冒頭に「⚠️『確認しない』にするとごみ箱へ移動する確認が出なくなります（誤削除注意）」を明記。`RecommendedValue=確認する`。
- **C の在席実機確認を DoD 追加（致命2）**：ShowRecent=「最近使ったファイル」の同定は標準知識（File Explorer Options>プライバシー：最近使ったファイル=ShowRecent / よく使うフォルダー=ShowFrequent）と出典で確信度高だが、24H2 実機での反映と file/folder 同定は在席で1回目視（DoD 追記）。
- **A は宣言的 Boolean 維持（Q2）**：`…\Explorer\Advanced` は他値同居の常在キー＝ExportKey は通常 export（削除マーカーなし）。既定 OFF で値 0 書込≒未設定＝復元機能的に無害。「完全な未設定への原状復帰ではない（値 0 が残る）」点は許容（全宣言的 Boolean 共通）。
- **Backup クラス命名（依存）**：誤コピー防止に `ConfirmFileDeleteBackup` / `ShowRecentBackup` と個別命名（StartTrackProgsBackup のラベル "記録する" を残さない）。
- **CategoryType 追加不要**（Shell 既存）。新規 Helper なし。
